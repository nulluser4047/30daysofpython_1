## 🇬🇧 English

### About this project

Hi! I'm Laura, and this repository documents my **30 Days of Python** learning challenge.

I'm learning Python from scratch, one concept and one exercise at a time. I'm interested in science, astronomy, technology, and eventually exploring ethical hacking. This challenge is a way to build strong programming fundamentals while having fun along the way.

This isn't a collection of perfect solutions: it's a **learning journal**. I'll share exercises, small projects, mistakes, improvements, and things I discover.

### My goals

- Understand the fundamentals of Python and programming logic.
- Write code independently instead of only copying examples.
- Learn to read error messages and debug my own programs.
- Practice consistently in Visual Studio Code.
- Build small, working projects and document my progress with GitHub.

### The 30-day roadmap

| Days | Focus | Topics |
|:---:|---|---|
| 01–07 | Fundamentals | `print()`, variables, data types, arithmetic, `input()`, strings, calculator project |
| 08–14 | Programming logic | Comparisons, `if / elif / else`, `while`, `for`, loop control, number-guessing game |
| 15–21 | Data and functions | Lists, tuples, sets, dictionaries, functions, return values, contacts project |
| 22–30 | Real projects | Modules, files, exceptions, debugging, Git/GitHub, `turtle`, final game |
